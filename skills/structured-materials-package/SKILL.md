# 结构化内容生成多格式资料包

## 输入与输出

输入：可信内容数据、主题与标题配置、输出目录、需要生成的格式、允许交付的附件清单。输出：按科目或单元组织的资料、单独的答案册、产物清单、验证报告及可选 ZIP 包。执行文档生成时使用环境已有的 Office 技能。

此 skill 是流程说明，不附带完整生成器；可在现有生成工具上实施。不要把课程题目、机构介绍或个人路径固化进通用 skill。

## 执行流程

1. **校验内容契约**：先确认字段结构、类型、编号唯一性、题目与答案对应关系、数量和分值合计。推荐采用 JSON 等纯数据输入；动态导入 Python 内容模块会执行代码，仅限可信本地内容。记录输入摘要，避免只依赖修改时间判断变化。
2. **参数化配置**：主题、课程名称、科目目录、每单元产物种类、文件名和附件来源全部放在配置中。外部信息注明来源及核验日期，不继承过期指南中的考试事实。
3. **建立构建清单**：列出每个单元应生成的演示稿、练习卷、练习答案、测试卷和测试答案。生成前一次性创建所有输出目录，避免首次构建依赖此前运行留下的目录。
4. **同源生成**：从同一份数据派生不同格式，题目与答案按稳定 ID 对齐；正文与答案分册。内容超出版式容量时拆页或明确报错，不用截取前几项来默默丢弃材料。
5. **检查产物**：按清单逐个确认文件存在、可打开、内容对应且非空；检查题目/答案编号、公式标记残留和总分。抽检长题、表格、公式及中英混排的实际渲染。验证结果区分结构检查、内容检查与视觉检查。
6. **隔离失败**：失败单元记录到报告并使批处理返回非零状态；保留成功产物用于排查。需要完整资料包时，未全部通过不得作为完整成品发布。
7. **清单归档**：只纳入本次通过校验的产物及明确授权的附件，不对整个工作目录无差别压缩。归档相对路径不得逃出输出根目录，拒绝绝对路径、父目录跳转及指向根目录外的链接；排除凭据、缓存、旧版产物和 ZIP 本身。
8. **验证后发布**：检查源目录非空、输出文件名唯一。在目标位置附近写临时 ZIP，运行完整性测试并比对条目、数量、大小及必要的摘要；全部通过才替换旧包。失败时保留旧包，不先删除再压缩。

## 验收与汇报

- 交付清单中的必需产物齐全，输入/输出对应关系可追溯。
- 文件可打开不代表排版正确；未渲染检查时必须如实注明。
- ZIP 条目与允许清单完全一致，解压路径受控，完整性检查通过。
- 报告生成数量、失败单元、验证范围、附件来源与交付位置。

## 提炼来源与改进边界

源自工作区批量资料生成和归档脚本中的结构化输入、同源多格式输出、答案分册和相对路径打包模式。原脚本的目录创建顺序、动态导入、整目录打包及先删旧包等问题通过本流程补充约束；这些要求是本次提炼后的建议，不是原脚本已经实现或验证的能力。
