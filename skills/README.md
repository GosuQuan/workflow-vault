# 可复用 skills

这里收录从工作区实践提炼的任务说明，而非课程内容副本。每个目录包含带 `name` 和 `description` 元数据的 `SKILL.md`；可由支持该约定的 agent 加载，或作为任务执行说明使用。宿主的具体技能目录和安装方式以其文档为准，本仓库不会自动注册技能。

| Skill | 适用任务 | 核心产出 |
| --- | --- | --- |
| [pptx-diagnose-and-reveal](pptx-diagnose-and-reveal/SKILL.md) | 课件文字颜色诊断、步骤与答案分次显示 | 修复副本与分层验收报告 |
| [traceable-text-collection](traceable-text-collection/SKILL.md) | 批量文本获取、缓存与失败重试 | 来源清单、文本与待复核报告 |
| [structured-materials-package](structured-materials-package/SKILL.md) | 结构化内容生成多格式资料并归档 | 资料包、产物清单及验证报告 |
| [layered-runtime-verification](layered-runtime-verification/SKILL.md) | 多入口或有状态网页应用的分层验证 | 覆盖矩阵、断言结果与验证边界 |
| [evidence-guided-review-loop](evidence-guided-review-loop/SKILL.md) | 模型或规则建议的证据审核、导出与执行复盘 | 审核快照、导出草稿及描述性复盘 |

这些是流程文档，不是已安装的软件或通用修复器。使用前应检查输入条件和所需工具；验证报告须区分静态检查、渲染检查与实际播放检查。
